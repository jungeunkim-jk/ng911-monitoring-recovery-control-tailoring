# Continuous Monitoring and Recovery Operations in NG9-1-1 Entities: Worked Example, version 0.1

A worked example of control tailoring and assessment procedures for NENA-STA-040.2-2024 Sections 5.6 (Continuous Monitoring) and 5.7 (Recovery Operations), using NIST SP 800-53 Revision 5.

Status: version 0.1, draft for review, 14 November 2026. The document has not been externally reviewed. Comments are welcome through the Issues tab of this repository.

Author: Jungeun Kim. Independent work; not a publication of the University of Florida and not a NENA publication.
